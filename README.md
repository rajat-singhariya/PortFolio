# Rajat Singhariya — Portfolio

Personal portfolio website: plain HTML, CSS and JavaScript (no build step).

Live: https://rajatsinghania-portfolio.vercel.app/

## Structure
- `index.html` — page skeleton
- `data/` — all content (profile, experience, skills, achievements, projects, services, social links)
- `css/style.css`, `js/main.js`, `js/render.js` — styling, animations, and the code that builds sections from `data/`
- `assets/` — photos, favicon, project screenshots
- `Rajat_Singhariya_Resume.pdf` — file behind the Download CV button

To update content, edit the files in `data/` — see `HOW-TO-EDIT.md`. Pushing to `main` redeploys on Vercel.
